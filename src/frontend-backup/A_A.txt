### 1. The proven extraction loop

For **every** file, you run this 5-step cycle. Do not skip steps. Do not improvise.

#### Step 1 — LOCATE: find every emission of the file

```bash
cd ~/Downloads
grep -nE 'PATH_PATTERN' gemini.md | grep -vE 'You said|user-query|placeholder'
```

`PATH_PATTERN` must be regex-flexible. See **Section 2** for pattern construction.

**What you're looking for:** every line number where the file path, its header comment, or its distinctive function signatures appear.

#### Step 2 — CLASSIFY: how many distinct emissions exist?

Look at the line numbers. Cluster them: hits within ~200 lines of each other are probably the **same emission** (file header + imports + body + closing). Clusters separated by thousands of lines are **different emissions**.

Common pattern:
- **V1:** First emission (~`L68000`)
- **V2:** Second emission, often after a bug fix or UI overhaul (~`L130000`)
- **V3+:** Rare, but happens (e.g., third iteration after role mismatch fix)

You will almost always want the **latest** emission, **plus** any small patches that appear after it.

#### Step 3 — EXTRACT: pull the raw bytes

For **each** emission you'll need, sed a window that covers start → end:

```bash
# Start 10-20 lines before first strong hit (to catch the header comment)
# End 10-30 lines after last signature hit (to catch the closing brace + next file marker)
sed -n 'START,ENDp' gemini.md > file_vN_raw.txt
wc -l file_vN_raw.txt
```

**Rule of thumb for window sizing:**
- Small file (30–100 lines of real code): window = ~150 lines
- Medium file (100–400 lines): window = ~500 lines
- Large file (400+ lines): window = ~1000 lines, or split into 2 seds

**Always check the raw file ends cleanly** — should end with `}` + blank lines + a new `// path/to/next-file.ts` header or `### Step N:` header. If it ends mid-function, your window is too narrow — extend END.

#### Step 4 — CLEAN: strip the Gemini HTML div noise

Raw sed output has `<div class="code-block...">` wrappers, `_ngcontent-ng-c...` attributes, `jslog="..."` blobs, `NextResponse\.json` escape backslashes, etc.

Two approaches depending on file size:

**A) Small files (< 300 lines):** paste the raw to the AI, AI cleans inline.

**B) Large files:** user runs this Python (put in `~/Downloads/clean_code_block.py`):

```python
#!/usr/bin/env python3
"""Strip Gemini HTML wrapper junk, keep only the code inside ``` fences."""
import re, sys

path = sys.argv[1]
lines = open(path, encoding="utf-8", errors="replace").read().splitlines()

out = []
in_fence = False
for ln in lines:
    # Enter fenced block
    if ln.strip().startswith("```"):
        in_fence = not in_fence
        continue
    if in_fence:
        # Unescape Gemini's aggressive escaping
        ln = ln.replace("\\`", "`").replace("\\|", "|").replace("\\$", "$")
        ln = ln.replace("\\_", "_").replace("\\*", "*").replace("\\[", "[")
        ln = ln.replace("\\]", "]").replace("\\{", "{").replace("\\}", "}")
        ln = re.sub(r"\\ ", " ", ln)  # \ before space
        out.append(ln)

print("\n".join(out))
```

Usage:
```bash
python3 ~/Downloads/clean_code_block.py file_vN_raw.txt > file_vN_clean.ts
head -20 file_vN_clean.ts   # verify: should start with "// path" or "import"
tail -10 file_vN_clean.ts   # verify: should end with "}" not "<div>"
```

If the file has **multiple code blocks** (initial + patches), the cleaner outputs them concatenated. Split manually or note block boundaries before cleaning.

#### Step 5 — VERIFY: cross-check against other versions + patches

Diff V1 vs V2 (if both exist):
```bash
diff -u file_v1_clean.ts file_v2_clean.ts | head -100
```

Then search for **small patches after V2**. Patches look like:

```bash

```

Common patch markers in prose:
- `**WHERE:** In src/app/.../FILENAME`
- `**WHAT TO REPLACE:**`
- `**CHANGE THIS:**`
- `**FIND:** ... **REPLACE WITH:** ...`
- `**Fragment N:**`
- `// where to swap` / `// patch` comments inside the code block
- Very short code blocks (< 20 lines) that reference the file

For each patch you find, **ask the user to paste it**, then manually apply to the V2 clean file. Do not skip patches — they contain critical fixes (auth routing, role checks, bug fixes, styling swaps).

#### Step 6 — DELIVER: hand the user the final merged file

### 3. The multi-scan Python tool (when grep alone isn't enough)

Save as `~/Downloads/find_file.py`. This runs **3 passes** (strong path / weak header / code signal) and clusters hits by proximity — essential for files emitted multiple times.

```python
#!/usr/bin/env python3
"""
Multi-pass file finder for gemini.md.
Usage: python3 find_file.py gemini.md path/to/file.ts
       python3 find_file.py gemini.md --signal bcrypt
"""
import re, sys

path = sys.argv[1]
query = sys.argv[2]

lines = open(path, encoding="utf-8", errors="replace").read().splitlines()

# Build 3 pattern tiers based on the query
if query.startswith("--signal"):
    signal_word = query.split()[1]
    STRONG = [re.escape(signal_word)]
    WEAK   = [rf"//\s*.*{re.escape(signal_word)}.*\.(ts|tsx)"]
    SIGNAL = [rf"\b{re.escape(signal_word)}\b.*\("]
else:
    fname = query.split("/")[-1]        # e.g. "seed.ts"
    fstem = fname.rsplit(".", 1)[0]     # e.g. "seed"
    ext   = fname.rsplit(".", 1)[-1]    # e.g. "ts"
    STRONG = [re.escape(query), re.escape(query.replace("/", "\\\\"))]
    WEAK   = [
        rf"//\s*.*[/\\]{re.escape(fstem)}\.{ext}",
        rf"\*\*FILE:\*\*\s*.*{re.escape(fstem)}\.{ext}",
        rf"^#+\s*Step\s+\d+.*{re.escape(fstem)}",
    ]
    SIGNAL = [
        rf"export\s+(default\s+)?(async\s+)?function\s+\w+",
        rf"^\s*import\s+.*from\s+['\"].*{re.escape(fstem)}",
    ]

def scan(pats, label):
    hits = []
    for i, ln in enumerate(lines, 1):
        for p in pats:
            if re.search(p, ln, re.I):
                hits.append((i, ln.strip()[:140]))
                break
    print(f"\n=== {label} — {len(hits)} hits ===")
    for i, ln in hits[:40]:
        print(f"L{i:>7}: {ln}")
    return [h[0] for h in hits]

strong = scan(STRONG, "STRONG (explicit path)")
weak   = scan(WEAK,   "WEAK (header heuristics)")
signal = scan(SIGNAL, "SIGNAL (code smells)")

all_hits = sorted(set(strong + weak + signal))
clusters = []
if all_hits:
    cur = [all_hits[0]]
    for h in all_hits[1:]:
        if h - cur[-1] <= 250:
            cur.append(h)
        else:
            clusters.append(cur); cur = [h]
    clusters.append(cur)

print("\n=== CLUSTERS (candidate file emissions) ===")
for c in clusters:
    print(f"  L{c[0]}–L{c[-1]}  ({len(c)} hits)  → sed -n '{c[0]-20},{c[-1]+50}p'")
```

Run for any file:
```bash
python3 ~/Downloads/find_file.py ~/Downloads/gemini.md src/app/page.tsx
```

**Interpreting clusters:**
- **1 cluster** → single emission, extract that range
- **2+ clusters** → multiple emissions (V1, V2…), usually pick the **last** cluster
- **Cluster near cluster** (gap < 500 lines) → file emitted + patched immediately → treat as one emission
- **Cluster very far apart** (gap > 5000) → truly different emissions; compare to see which is newer

| Pitfall | Symptom | Fix |
|---|---|---|
